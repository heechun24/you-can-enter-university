원서 접수 사이트 회원가입 및 원서 작성 준비

  • 유웨이어플라이 바로가기
  • 진학어플라이 바로가기

1) 유웨이어플라이에 접속해서, 오른쪽 위 회원가입 버튼 클릭

2) '공통 원서접수 회원가입' 클릭

3) '통합회원 가입' 클릭

4) 회원가입 마무리 후 메인 페이지에서 '공통원서작성' 클릭

5) 공통원서 비밀번호 설정: 잊어버리지 않게 회원가입한 비밀번호랑 같은 것 권장

6) 공통원서 내용 입력: 지원자 정보 입력 시 주소 정확히 입력, 휴대전화 정확히 입력, 추가 전화번호에 보호자 번호 정확히 입력

7) 공통원서 내용 입력: 학교 정보 입력 시 졸업(예정)연도는 2027학년도 2월로 입력, 고교 대표 전화번호는 고교검색 하면 자동 입력됨

8) 공통원서 내용 입력: 전형료 환불 계좌 정보 입력 및 인증, 입력 안 하면 환불 발생 시 대학 직접 방문해 현금 수령 필요

9) '저장' 버튼 클릭

10) 저장 뒤 '진학어플라이로 내보내기' 버튼 클릭

11) 1분정도 기다린 뒤 진학어플라이 페이지 접속, 공통원서접수 로그인 (회원가입은 이미 한 번에 된 상태임)

12) '공통원서작성' 버튼 클릭

13) 공통원서 비밀번호 입력

14) 유웨이어플라이에서 입력했던 내용이 잘 불러와졌는지 모두 점검 후, 가장 아래 '저장하기' 버튼 클릭

여기까지 하면 원서 작성 준비 끝

원서 접수

1) 모집요강을 반드시 먼저 최종 점검하기

2) 원서접수 사이트(유웨이/진학 상관 없음)에 접속하여 지원하려는 학교 검색하기

3) '4년제 수시' 또는 '전문대학(교) 수시(1차)' 확인, 지원하려는 학교 이름 정확히 확인하고 클릭하기
접수 사이트가 다르면 여기서 자동으로 넘어가짐

4) 필요한 내용을 입력, 전형/학과를 정확하게 확인한 후 결제창으로 넘어가기
(예를 들어 '일반고'와 '일반전형'은 다릅니다. '정원 외' 전형과 '정원 내' 전형은 다릅니다. 결제한 원서는 취소가 불가하므로 반드시 잘 확인해야 합니다.)

5) 학생부 온라인 동의여부에 '동의'하지 않으면 대학으로 생활기록부가 전송되지 않습니다. 꼭 동의해 주세요.

6) 결제 완료 후 반드시 수험번호를 확인합니다.

7) 경쟁률을 비교해보고 지원하고 싶은 학교는 마감일을 체크하고, 최종 경쟁률 발표 시간도 함께 확인해주세요.

접수하다 보면 종종 필요한 우리 정보

학교명: 곤지암고등학교
주소: 경기도 광주시 곤지암읍 곤지암로 82
학교 유형: 종합고등학교 (종합고가 없으면 일반계열은 일반계고등학교, 특성화계열은 특성화고등학교)
졸업 예정 연월: 2027년 2월(실제 졸업식 날짜와 상관 없음)
졸업식 예정일: 2026년 12월 31일

서류 제출

1) 원서 결제 후 원서접수 사이트의 내 원서함에서 필요 서류 목록 확인하기

2) 모집요강에 적힌 대학별 요구사항 반영하기
(생기부 위에 수험번호 쓰라는 경우, 학교 주소 쓰라는 경우도 있습니다. 대학별 모집요강에서 꼭 확인해 주세요.)

3) 서류 완성되면 선생님에게 들르기

4) 이후 봉투 표지에 적힌 서류 하나하나 체크하면서 봉투에 넣기

5) 우체국에 가서 '빠른 등기-익일특급'으로 보내기
(익일특급은 아니어도 되지만, 반드시 '등기우편'으로 보내 주세요. 등기우편만 운송장추적이 가능해요.)
